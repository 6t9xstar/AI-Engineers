# Contributing to AI-Engineers

We welcome contributions from AI engineers, systems programmers, and researchers!

## How to Contribute
1. **Add a Cookbook Recipe**: Implement a clean, zero-dependency or minimal-dependency pattern under `cookbook/<category>/`.
2. **Improve a Roadmap Guide**: Update technical formulations, benchmarks, or modern architectural diagrams in `roadmap/`.
3. **Add a Glossary Term**: Add missing foundational terms under `glossary/terms/<term_id>.md`.
4. **Fix Bugs & Types**: Keep all recipes tested and passing via `python ai_engineers.py test`.

## Commit Style
Follow Conventional Commits:
- `feat(...)`: New architectural recipe or roadmap guide.
- `fix(...)`: Bug fix in cookbook or script.
- `docs(...)`: Documentation and cheat sheet improvements.
